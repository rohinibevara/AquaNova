# AquaNova 🌊

Smart Autonomous River Pollution Forecast, Cleaning & Water Filtration Bot

## Features
- Cloud data logging using ThingSpeak
- Virtual sensor simulator
- AI pollution prediction model
- Future: Cleaning + filtration robot

## Tech Stack
- Python
- ThingSpeak
- Scikit-learn
- Pandas

## How to Run
1. Run simulator/data_generator.py
2. Wait for data
3. Export CSV from ThingSpeak
4. Train model: python ml/train_model.py
